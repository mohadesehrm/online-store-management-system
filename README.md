# Online Store Management System

A modular CLI-based online store management system developed with Python.

This project simulates the core operations of a small online store, including product and customer management, order processing, inventory control, and store reporting.

All application data is stored persistently in JSON files instead of a database.

## Features

- Product management
- Customer management
- Order management
- Inventory control
- Store reports
- JSON-based data persistence
- Input validation and exception handling
- Modular project architecture

## Tech Stack

- Python 3
- JSON
- Command Line Interface (CLI)
